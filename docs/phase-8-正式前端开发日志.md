## 自测与验证

### 1. 构建验证

命令：

```powershell
$env:NEXT_DIST_DIR='.next-buildcheck'; npm run build
```

结果：通过。

说明：

- 默认 `.next` 目录在当前环境下出现缓存锁文件，导致 `next build` 直接写入时报 `EPERM`
- 因此改用临时 `distDir` 完成生产构建校验

### 2. 类型验证

命令：

```bash
npx tsc --noEmit
```

结果：通过。

说明：

- 构建后已把临时类型引用恢复为正常状态
- 再执行纯类型检查，确认当前工作区是干净可编译的
